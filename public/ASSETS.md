# Assets da Hope Business

Coloque os arquivos estáticos do site dentro de `public/`.

## Logo
- `public/Hop.png`

O mesmo arquivo é usado automaticamente no:
- cabeçalho;
- footer;
- painel administrativo;
- assistente virtual.

## Vídeos
- `public/videos/hero.mp4`
- `public/videos/regiao.mp4`

## Imagens institucionais opcionais
- `public/images/hero.jpg`
- `public/images/region-poster.jpg`

Se essas imagens não existirem, o site continua com o fundo visual de fallback local.

Imagens dos imóveis cadastrados pelo painel continuam sendo armazenadas no Supabase Storage.
